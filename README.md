This project explores the implementation of CasaOS on the STB HG680P (a low-power ARM-based Set Top Box) to transform it into a fully functional and energy-efficient home server. By installing Armbian—a lightweight Debian-based Linux distribution optimized for ARM devices—this project repurposes old hardware for modern server applications.
